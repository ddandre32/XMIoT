# 小米IoT接口管理项目 - 架构设计文档

## 概述

本项目是一个完整的小米智能家居设备管理解决方案，采用分层架构设计，提供从底层SDK到上层API的完整功能栈。

### 2. 模块职责

#### 2.1 SDK层 (miot_sdk/)

- **client.py**: 主客户端，整合所有功能
- **cloud.py**: HTTP客户端，处理与小米云的通信
- **lan.py**: 局域网设备发现
- **spec.py**: 设备SPEC解析
- **storage.py**: 本地数据缓存
- **types.py**: 数据类型定义
- **error.py**: 异常定义

#### 2.2 服务层 (core/)

- **device_manager.py**: 设备管理业务逻辑
- **scene_manager.py**: 场景管理业务逻辑
- **notification_service.py**: 通知服务

#### 2.3 接口层 (api/, mcp/)

- **api/**: RESTful API服务
- **mcp/**: Model Context Protocol服务

## 接口设计

### RESTful API设计原则

- **资源导向**: 以设备、场景等资源为核心
- **统一接口**: 使用标准HTTP方法（GET/POST/PUT/DELETE）
- **版本控制**: URL路径中包含API版本（/api/v1/）
- **错误处理**: 使用HTTP状态码和统一的错误格式

### MCP设计原则

- **工具化**: 每个功能封装为一个工具
- **类型安全**: 使用Pydantic模型验证参数
- **描述清晰**: 为AI提供清晰的功能描述

## 安全设计

1. **OAuth2认证**: 使用小米官方OAuth2流程
2. **API加密**: 使用AES加密通信内容
3. **Token管理**: 自动刷新access_token
4. **错误隐藏**: 不向客户端暴露内部错误细节

## 扩展性设计

### 1. 设备类型扩展

通过SPEC机制自动支持新设备类型，无需修改代码。

### 2. 服务层扩展

可以添加新的Manager类来扩展功能：

```python
class NewFeatureManager:
    def __init__(self, miot_client: MIoTClient):
        self._client = miot_client
```

### 3. 接口层扩展

添加新的路由或MCP工具非常简单：

```python
# API路由
@router.post("/new-feature")
async def new_feature(...):
    pass

# MCP工具
@self._mcp.add_tool
def new_tool(...):
    pass
```

## 性能优化

1. **缓存机制**: 设备列表、SPEC等信息本地缓存
2. **批量操作**: 支持批量属性读写
3. **异步设计**: 全异步架构，支持高并发
4. **连接复用**: HTTP连接池复用

## 总结
